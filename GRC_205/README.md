This repository contains a comprehensive Incident Response Plan (IRP), ransomware response strategy, evidence preservation framework, communication plan, tabletop exercise, and post-incident improvement roadmap developed for the fictional **Northbridge Skills Institute**.

## Scenario Summary

Northbridge Skills Institute experienced a suspected ransomware attack affecting critical systems shortly before a scheduled online examination.

Key indicators included:

- Suspicious email attachment opened by a finance officer.
- Unusual Microsoft 365 sign-in activity.
- Unauthorized service account usage.
- Large-scale outbound data transfer.
- File encryption on shared storage.
- Learning Management System (LMS) disruption.
- Potential compromise of backup infrastructure.

The incident required immediate containment, investigation, recovery planning, evidence preservation, and executive communication.
